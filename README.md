## 📋 Overview

Visitors to NGO websites often struggle to find information quickly. This chatbot provides instant answers about the foundation's work, projects, donations, and volunteering - eliminating wait times and reducing staff workload.

---

## ✨ Features

- 🏛️ **Foundation Info** - Explains mission in education, healthcare, nutrition, and community welfare
- 📘 **Project Details** - Specific information on Shiksha, Manthan, and Pravah programs
- ❤️ **Donation Guidance** - Shows amounts (₹500-₹5000), 80G tax benefits, direct donate link
- 🙋 **Volunteering** - Lists roles, benefits, and links to application form
- 📞 **Smart Contact** - Separate responses for phone, email, and address queries
- 🔍 **Spelling Correction** - Detects typos and suggests corrections
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile

---

## 🛠️ Technology

Built with **pure HTML, CSS, and vanilla JavaScript** - no frameworks, no dependencies. Easy to integrate into any website.
**How it works:** Keyword intent matching → Spelling correction → Priority response generation → Feedback collection
